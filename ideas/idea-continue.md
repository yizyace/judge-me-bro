## Problem
As AI-generated code floods repos, teams struggle to enforce their own conventions,
security patterns, and architecture boundaries at scale.

## Solution
Continue lets teams define AI checks as markdown files in the repo — each a full AI
agent — that run as native GitHub status checks on every PR, keeping standards
"decided by humans, enforced by AI."

## Market
Engineering teams from startups to Fortune 500 adopting AI coding tools.

## Team

Michigan) and Nate Sesti (MIT '23; first hire at Mayan, YC W21; built mission-control
software at NASA JPL).

## Traction

## The Ask
