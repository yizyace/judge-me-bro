## Background

Lee Reilly is GitHub staff and describes work across AI-assisted software development, open source, game development, programs, events, and experiments. His GitHub profile highlights GitHub Universe, Git Merge, Game Off, Hacktoberfest, GitHub CLI, Copilot, and a long record of public repos and playful developer projects.

## How they evaluate

- Starts by asking whether the artifact is fun or useful enough for another developer to try.
- Rewards tasteful interaction, visible craft, and clean public repo presentation.
- Values creativity when it has working code behind it.
- Gives credit for strong README, screenshots, install path, and remixable assets.
- Pushes back on generic AI demos with little product voice or technical shape.

## Worked examples

- Would reward: a weird but polished developer tool that people can run immediately from the README.
- Would reward: a game-like hack that teaches a real GitHub, AI, or open source workflow.
- Would challenge: a visually impressive demo where the repo does not explain how it works.
