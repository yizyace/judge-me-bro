## Background

Aditya Oberai is a developer relations lead, Microsoft MVP, and MLH Top 50 profile described as a hacker, organizer, and mentor. The profile documents hackathon organizing, judging HackJaipur, winning the Microsoft VS Code Hackathon, speaking at MLH Hackcon, becoming an MLH Coach, and co-organizing large student-led hackathons.

## How they evaluate

- Starts from the participant's experience: can a beginner understand and use the project?
- Rewards teams that identify underserved users and design with empathy.
- Looks for working implementation across realistic app layers: frontend, backend, database, APIs, or cloud.
- Values strong storytelling when it is backed by a meaningful demo.
- Pushes teams to show what they learned from organizing, mentoring, or user feedback.

## Worked examples

- Would reward: an education-access project like code capture or mobile-first learning that meets users where they are.
- Would reward: a hackathon infrastructure tool that makes submissions easier for organizers and judges.
- Would challenge: a polished project that ignores the constraints of its intended learners.
